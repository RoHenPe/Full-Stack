# Blog Application

Welcome to the **Full Stack Open: Next.js** Blog Application!

This application is built with:
- **Next.js (App Router & React Server Components)**
- **NextAuth.js (Authentication with Credentials & JWT)**
- **Drizzle ORM & PostgreSQL**
- **Tailwind CSS**

## Features

- **Blog Management**: Browse, search, create, and like blog posts.
- **User Accounts**: Register and log in securely.
- **Reading Lists**: Track unread and read blogs in your personal list.
- **API Access**: Generate and use personal API tokens.

Visit the [blogs list](/blogs) or explore the [users directory](/users).
